# Componentes externos

A licença MIT cobre o código deste projeto, não concede licença sobre Android SDK,
ADB, marcas Samsung/Google/Netflix ou aplicativos Android mencionados no catálogo.

ADB / Android SDK Platform Tools é fornecido pelo Google. O repositório e o ZIP de
código-fonte não incluem seus binários. Cada usuário deve obter o Platform Tools
Windows na página oficial e manter os avisos e termos que o acompanham:

https://developer.android.com/tools/releases/platform-tools

Para executar consultas e operações no celular, extraia a pasta `platform-tools`
ao lado do executável. Compilação, demonstração e testes não exigem ADB.

O programa usa as bibliotecas do .NET Framework instaladas no Windows. Não contém
bibliotecas de terceiros copiadas, APKs ou bancos comunitários de debloat importados.
